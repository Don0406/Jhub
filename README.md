# J-Hub | Capstone Project Setup

Welcome to the **J-Hub** repository! J-Hub is a multi-dimensional transportation and travel management platform designed to streamline tour operations, match joiners, manage financials, track live route data, and provide real-time digital manifests for field staff.

Follow the guide below to clone the project, build it, and run it locally on your machine.

---

## 🚀 Quick Start Guide (How to Clone & Run)

### Prerequisites
Make sure you have the following installed on your machine:
* [.NET 10 SDK](https://dotnet.microsoft.com/download) (or higher)
* [Git](https://git-scm.com/downloads)
* [Visual Studio Code](https://code.visualstudio.com/) or Visual Studio 2022

---

### Step 1: Clone the Repository
Open your terminal (PowerShell, Command Prompt, or VS Code Terminal) and run:

```bash
git clone https://github.com/Don0406/Jhub.git
cd Jhub/"[UPDATED] Capstone with Backend"
